# Customer Support Chatbot using LLM

## Overview

It is a simple **LLM-powered Customer Support Chatbot** built as a learning project to understand how Large Language Models can be integrated into real-world customer support applications.

The project focuses on building a clean and modular architecture while learning concepts such as LLM integration, prompt engineering, knowledge retrieval, conversation memory, and API development.

This repository is being developed incrementally, with each milestone introducing a new concept.

---

## Objectives

* Learn how to integrate Gemini LLM into Python applications.
* Build a customer support chatbot from scratch.
* Understand prompt engineering.
* Implement a simple knowledge base.
* Maintain conversation history.
* Build a clean and maintainable project structure.
